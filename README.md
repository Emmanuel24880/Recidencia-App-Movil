# 📱 Honorata Movil

## 📋 Descripción del Proyecto

**Honorata Movil** es una aplicación móvil desarrollada para el personal de servicio del restaurante Honorata. La plataforma permite a los meseros gestionar pedidos de manera rápida y eficiente, consultando en tiempo real los productos registrados desde Honorata Web y manteniendo comunicación directa con el módulo de cocina.

La aplicación se integra con el ecosistema Honorata, permitiendo que la información de productos, pedidos y estados de preparación se sincronice automáticamente mediante servicios en la nube.

---

## 🎯 Objetivo

Facilitar el proceso de toma y seguimiento de pedidos dentro del restaurante, mejorando la comunicación entre meseros y cocina, reduciendo tiempos de espera y optimizando la atención al cliente.

---

## 🚀 Funcionalidades Principales

### 🔐 Inicio de Sesión

La aplicación está diseñada para uso exclusivo del personal de servicio.

#### Características

* Autenticación segura mediante credenciales.
* Acceso restringido a usuarios autorizados.
* Gestión de sesiones.

---

### 🍽️ Consulta de Productos

Permite visualizar el catálogo de productos disponible en tiempo real.

#### Características

* Sincronización automática con Honorata Web.
* Consulta de categorías.
* Visualización de precios.
* Visualización de imágenes.
* Consulta de disponibilidad de productos.

---

### 📝 Gestión de Pedidos

Facilita la captura de órdenes realizadas por los clientes.

#### Características

* Creación de nuevos pedidos.
* Selección de productos.
* Registro de observaciones especiales.
* Asociación de pedidos a mesas.
* Cálculo automático del total.

---

### 👨‍🍳 Comunicación con Cocina

Permite el envío y seguimiento de pedidos en tiempo real.

#### Características

* Envío automático de pedidos al módulo de cocina.
* Actualización del estado de preparación.
* Seguimiento del progreso de cada orden.
* Sincronización instantánea entre dispositivos.

---

### 🔔 Sistema de Notificaciones

Mantiene informado al mesero sobre el estado de los pedidos.

#### Características

* Notificaciones cuando un pedido entra en preparación.
* Notificaciones cuando un pedido está listo.
* Actualización en tiempo real.
* Mejora en los tiempos de entrega al cliente.

---

### 💰 Gestión de Cobro

Permite finalizar el servicio de manera eficiente.

#### Características

* Consulta del total del pedido.
* Registro de pagos.
* Actualización automática de ventas.
* Cierre de órdenes.

---

## 🔄 Integración con Honorata Web

La aplicación forma parte del ecosistema Honorata y se conecta directamente con:

* Honorata Web (Administración).
* Módulo de Cocina.
* Base de datos centralizada.

Toda la información se sincroniza en tiempo real para garantizar consistencia y disponibilidad de los datos.
